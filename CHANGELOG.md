# Changelog

## v2.0
- Split into two apps: Media Combo (Movie, Mouse) and Keys Combo (Mouse, Keynote, Keyboard, Numpad), each for Bluetooth and USB.
- New Keyboard mode (stock keyboard view with the Back gestures).
- Mouse uses the motion engine and settings of Better Mouse 1.2; hold OK for scroll mode, Back + OK for drag lock.
- Movie: double tap Left/Right changes playback speed, hold OK resets it.

## v1.x
- Remote Combo: several HID modes in one app, swap with a long Back, next mode with a double tap of Back.
- Shares the pairing keys of the stock Remote app.
- Upright screen layouts for Movie and Mouse.
